💡 How the engine decides (transparent rules)
  • ⏱ Temporal proximity: deploy within 5 min before first error → strong signal.
  • 🔤 Keyword overlap: same component (Redis / DB / payment) in deploy + errors → boosts score.
  • 📊 Frequency: repeated same error signature → grouped as one related-error cluster.
  • 🔗 Cascade check: downstream errors after upstream are treated as effect, not cause.
  • 🎯 Confidence: High = deploy + keyword + timing all align. Med = 2 signals. Low = 1 signal.
